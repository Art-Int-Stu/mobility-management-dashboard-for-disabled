## 칸 채우기 요령
- 확신도: 상=출처 2개 교차 확인 / 중=단일 출처 / 하=출처 없음
- 영향: 이게 틀리면 주 지표(평균 대기·지니)가 흔들리는가 — 하/중/상
- 방향: 모델 산출이 실제보다 커지면 + / 작아지면 − (대기시간 기준: −면 낙관적 모델)
- 위험: 매트릭스 — (확신도 하 × 영향 상)=XX, (하×중)·(중×상)=X, 나머지 ✓
- 조치 메뉴: 시나리오 분석 / 결정변수 승격 / 정보 추가 확보 / 민감도 / 보고 명시 / 범위 제외
- 단순화에는 확신도 없음(정의상 항상 낮음) — 칸 자체가 없다
- 이견 시 낮은 확신도 채택, 평가는 팀 토의로
