# 데이터 설명 (Data Dictionary)

이 문서는 `데이터/` 및 `데이터/api/` 아래 모든 파일이 **무슨 데이터인지, 어디서 왔는지, 서로 어떻게 연결되는지**를 정리한다.
수집 배경·검증 과정은 [seoul-open-api-collection.plan.md](../docs/01-plan/features/seoul-open-api-collection.plan.md) 참고.

## 1. 원본 보유 파일 (`데이터/` 루트)

### `서울시설공단_장애인콜택시 탑승내역_20251231.csv`
- **무엇**: 서울시설공단이 별도 제공한 장애인콜택시 **건별 탑승 내역** 원본. 2024-12-31 ~ 2025-12-31, **1,729,476행**.
- **컬럼**: 접수일시·예정일시·배차일시·승차일시·하차일시·취소일시, 출발구·출발동, 목적구·목적동, 이용목적, 요금, 승차거리, 차량구분, 장애유형
- **특징**: 취소 건(취소일시 존재)까지 전부 포함 — 아래 API 수집본(§2)보다 상위 데이터.
- **역할**: API 수집본의 검증 기준 및 병합 소스. `데이터/api/csv/calltaxi_2025_병합.csv`에 흡수됨.

### `주차장_평균이용률_정보공개청구(17078071) 공개내용.xlsx`
- **무엇**: 정보공개청구로 받은 **공영주차장 이용률·잔여구획** 자료 (API에는 없는 정보).
- **시트 4개**:
  | 시트 | 내용 | 컬럼 |
  |---|---|---|
  | `2024 주차이용효율` / `2025 주차이용효율` | 주차장별 **월별 일평균 주차이용효율(%)** = (일평균 이용대수×이용시간)÷(면수×운영시간)×100 | 월, 평일/주말 구분, 주차장명, 급지, 주차면수, 운영시간, 이용효율(%) |
  | `2024 피크시간 잔여` / `2025 피크시간 잔여` | 주차장별 **일자별 피크시간대와 그때 잔여구획 수** | 처리일자, 주차장명, 운영방식(직영/위탁), 피크시간, 잔여구획 |
- **역할**: 아직 미사용. 입지 분석 단계에서 "혼잡도" 지표로 활용 예정. 주차장명이 키라 `공영주차장_목록.csv`의 `PKLT_NM`과 명칭 매칭 필요(코드 없음, 정규화 매칭 필요).

## 2. API 수집 데이터 (`데이터/api/`)

서울 열린데이터광장 API 3종([OA-13122](https://data.seoul.go.kr/dataList/OA-13122) 공영주차장, [OA-15558](https://data.seoul.go.kr/dataList/OA-15558) 장애인콜시스템, [OA-21709](https://data.seoul.go.kr/dataList/OA-21709) 시영주차장)에서 수집. 수집 스크립트: `../scripts/collect_calltaxi.py`, `collect_parking.py`, `clean_calltaxi.py`, `cross_validate.py`, `merge_calltaxi.py`.

> **CSV 실 데이터 파일은 전부 `데이터/api/csv/`에 있으며 `.gitignore` 처리되어 git에 올라가지 않는다.** 리포트(.md)만 `데이터/api/`에 남아 git 추적됨. 스크립트를 재실행하면 `csv/`가 자동 재생성된다.

### 2-1. 콜택시 운행기록 (disabledCalltaxi, 2025년 전체)

모두 `데이터/api/csv/` 아래 위치 (gitignore 처리, 로컬에만 존재).

| 파일 | 무엇 | 행 수 | 언제 쓰나 |
|---|---|---:|---|
| `csv/calltaxi_2025.csv` | **원본** — API에서 365일 매일 호출한 결과를 그대로 이어붙임 | 1,495,624 | 원본 대조·재검증 필요 시만 |
| `csv/calltaxi_2025_정제.csv` | 완전중복 제거 + 시각 포맷 정규화(ISO) | 1,488,498 | 원본 대신 기본으로 사용 |
| `csv/calltaxi_2025_병합.csv` | **최종 분석용.** 정제본에 보유CSV의 접수일시·하차일시·이용목적·요금·승차거리·차량구분_보유·장애유형 컬럼을 매칭 병합 (매칭률 99.3%) | 1,488,498 | **분석은 원칙적으로 이 파일 사용** |
| `csv/calltaxi_2025_보유CSV_미매칭.csv` | 보유CSV에는 있지만 API에는 없는 잔여 행 — 대부분 **취소 건** | 251,554 | 취소율·수요 대비 실제 이행률 분석 시 |

**컬럼 설명 (`csv/calltaxi_2025_병합.csv` 기준)**

| 컬럼 | 의미 | 비고 |
|---|---|---|
| `date` | 수집 대상 일자 (YYYYMMDD) | API 호출 파라미터 |
| `no` | 차량 식별 번호로 추정 | 개인정보 아님(차량 단위) |
| `cartype` | 차량 종류 (API 원본 표기, 예: "중형 승합") | |
| `receipttime` | **API 필드명은 "접수"지만 실제로는 보유CSV의 `예정일시`에 대응** (매칭률 94~96%로 검증) | ⚠️ 아래 주의사항 참고 |
| `settime` | 배차일시 | |
| `ridetime` | 승차(탑승)일시 | |
| `startpos1` / `startpos2` | 출발 자치구 / 행정동 | |
| `endpos1` / `endpos2` | 도착 자치구 / 행정동 | |
| `접수일시` | **보유CSV에서 병합** — 실제 콜 접수 시각 (receipttime=예정일시와 별개) | 미매칭 시 공란 |
| `하차일시` | 보유CSV에서 병합 — 목적지 도착 시각 | 미매칭 시 공란 |
| `이용목적` / `요금` / `승차거리` / `차량구분_보유` / `장애유형` | 보유CSV에서 병합된 부가 정보 | 미매칭 시 공란 |
| `매칭여부` | Y = 보유CSV와 매칭 성공 / N = API에만 있음(0.7%) | |

> ⚠️ **중요 — receipttime 해석 주의**: API의 `receipttime`은 이름과 달리 실제 "접수" 시각이 아니라 "예정(호출)" 시각에 대응한다. 배차대기시간 등을 계산할 때는 `settime - receipttime`(배차−예정) 과 `settime - 접수일시`(배차−실접수, 병합본에서만 가능)를 구분해서 써야 한다. 근거: [cross_validate_리포트.md](api/cross_validate_리포트.md).

## 3. 파일 관계도

경로는 모두 `데이터/` 기준. `api/csv/` 아래는 gitignore 처리(로컬 전용).

```
[보유] 탑승내역_20251231.csv (172만행, 취소 포함) ─┐
                                                    │ 예정일시=receipttime 매칭 (99.3%)
[API] api/csv/calltaxi_2025.csv (원본, 150만행)     │
   └─ 중복제거+정규화 → api/csv/calltaxi_2025_정제.csv
         └─ 보유CSV 병합 ──────────────────────────┴→ api/csv/calltaxi_2025_병합.csv  ★분석용 최종
                                                    └→ api/csv/calltaxi_2025_보유CSV_미매칭.csv (취소건 등)

[API] api/csv/공영주차장_목록.csv (2,189개, 좌표 포함) ─┐
[API] api/csv/시영주차장_목록.csv (122개)  ─────────────┴→ PKLT_CD 대조 → api/시영공영_대조_리포트.md
                                                          (공영 목록의 시영여부 컬럼에 결과 반영됨)

[보유] 주차장_평균이용률_...xlsx ── (미사용, PKLT_NM 명칭 매칭 필요) ──→ 향후 입지 분석에서 결합 예정
```

## 4. 재현 방법

1. `mobility-management-dashboard-for-disabled/.env`에 `API_KEY` 설정
2. `python scripts/collect_parking.py` — 주차장 목록 2종 + 대조 리포트 생성
3. `python scripts/collect_calltaxi.py` — 2025년 콜택시 운행기록 365일 수집 (중단 시 재실행하면 체크포인트로 이어받음)
4. `python scripts/clean_calltaxi.py` — 중복 제거·시각 정규화
5. `python scripts/cross_validate.py` — 보유 탑승내역 CSV와 표본 대조 (선택)
6. `python scripts/merge_calltaxi.py` — 보유CSV 컬럼 병합 → `csv/calltaxi_2025_병합.csv` 생성
