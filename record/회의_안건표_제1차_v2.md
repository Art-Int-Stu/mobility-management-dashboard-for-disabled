## 1부 — 기결정 이해 공유 (재결정 아님, 질의만)

**대상**: D-05(비용=성과지표), D-07(DES 채택), D-08(수요 3층), S-01(교통 외생), S-02(예약콜 차감)

- 정할 것: 없음 — 이해 확인만
- 풀리는 것: 2부·3부 논의의 공통 전제. 특히 S-02 이해가 07~24시 잠정값(2-3(b)) 논의의 전제
- 안 하면: 2부에서 기결정 재론으로 시간 소모

## 2부 — 결정·확정

### 2-1. D-01 문제 문장 확정

- **정할 것**: v3안 채택 또는 수정 채택(수정부 명기)
- **풀리는 것**: 결정기록 D-01 완결. 이후 모든 문서의 상위 참조점 고정
- **안 정하면**: 보고·논문 서술의 기준 문장 부재 상태 지속 (다른 사슬은 안 막힘 — 후순위 배치 가능)

### 2-2. 기정리 5건 추인 + 참여·일자 칸 확정

- **정할 것**: D-02 문구 / D-03=(a) / D-09 OCI 역할 / D-10 반경 3km / A-04 상태(XX·사용 금지)를 전원 확인. 이견 항목만 "D-XX 변경"으로 재론
- **풀리는 것**: 미결 #3 소거, 결정기록 완결. D-10 추인은 공백 동 지표(지표 정의표) 확정의 전제
- **안 정하면**: 결정기록에 "참여 미기재" 결함 잔존 — 방법론 재료로서의 이력 신뢰도 훼손

### 2-3. ★ D-04 — 3분할 진행 (이 회의의 본론)

**(a) 즉시 확정 (인터뷰 불요 — 기술 정합 사안)**

- **정할 것**: 평균 대기 산식 / 지니 산식(실측 0.095 산출 방식과 일치, 소표본 처리 포함 — P-2 기반) / 신뢰구간 방법 / 공백 동 수 CI 불요 여부
- **풀리는 것**: 지표 정의표 v2 부분 완성
- **안 정하면**: 관문 C 채점표의 골격 부재

**(b) 잠정값 + 질문지 승인 (인터뷰 대기 4건)**

- **정할 것**: 50분 채택 근거·07~24시 유지/삭제·지니 가중(동 동등 vs 콜 수)·허용 오차 수준의 **잠정값**(P-3) + 인터뷰 질문 목록(P-4) 승인. 잠정값은 확정 아님을 기록에 명시
- **풀리는 것**: **인터뷰 요청 발신 가능** (3-1) — 청록 사슬 전체의 관문
- **안 정하면**: 인터뷰 요청이 질문지 없이 못 나감 → 리드타임만큼 D-04 완결이 통째로 밀림

**(c) 마감 규칙 의결**

- **정할 것**: 시한까지 인터뷰 미성사 시 → 잠정값을 "실무자 요구 가정"으로 ASSA 등재 후 확정, 인터뷰는 사후 검증 전환(D-03 패턴). **마감 시점 후보: 관문 A 워크스루일** (필수 조건은 캘리브레이션 결과 확인 전 — Sargent). 아울러 결정기록에 새 줄 등재: "D-04 변경: 분할 확정, 사유 = 실무자 정보 환경 확인 필요"
- **풀리는 것**: 인터뷰 지연·미성사 시에도 청록 사슬이 정지하지 않는 안전판
- **안 정하면**: 인터뷰가 안 오면 지표정의표 v2 무기한 정지 → 관문 C 준비 불능

### 2-4. D-06 라이선스 MIT 여부

- **정할 것**: MIT 채택 여부
- **풀리는 것**: STARS 목록화 §1 E1 완결, 저장소 공개 설정 진행 가능
- **안 정하면**: 저장소 라이선스 파일 부재 지속 (독립 사안 — 5분 내 처리)

### 2-5. A-01 등재 여부

- **정할 것**: "유휴 차량 최근접 거점 복귀" 가정의 ASSA 정식 등재 여부 (현재 예시 상태)
- **풀리는 것**: 조치란의 3변형 민감도·청구 9-4 대기가 공식 추적 대상이 됨
- **안 정하면**: 콜체인·청구 결과가 와도 걸어둘 가정 항목이 없음

### 2-6. ★ 정합성 2건

- **정할 것**: ⑴ A-07 조치란의 "(D-12)" — 예정 번호 부여 또는 조치 문구 수정 ⑵ A-05 결번 사유 한 줄 기록(삭제/결번 구분)
- **풀리는 것**: ASSA↔결정기록 교차 참조 무결성
- **안 정하면**: 관문 A 워크스루(항목별 검독)에서 어차피 걸림 — 지금 처리가 싸다

## 3부 — 담당·기한 배정 (배정 자체가 결정)

> 배정 순서 = 사슬 우선순위. 3-1·3-2가 리드타임 사안이라 최우선.

### 3-1. ★ 인터뷰 요청 발신 [청록 사슬 관문]

- **정할 것**: 담당·발신 기한 (질문지는 2-3(b) 승인본 사용)
- **풀리는 것**: D-04 잔여 4건 + S-03 사후 검증 + A-02 세부 조건 — 세 갈래가 한 발신에 걸림
- **안 정하면**: 리드타임 사안이라 하루 미룰수록 마감규칙 발동 확률 상승

### 3-2. 청구 9-4 확인·접수

- **정할 것**: 제출 여부 확인 담당, 미제출 시 접수 기한
- **풀리는 것**: A-01 조치(콜체인 대조)의 근거 입수 경로
- **안 정하면**: A-01이 등재돼도(2-5) 조치 불능 상태 지속

### 3-3. A-03 검증 — 정기접수 기록 방식 [보라 사슬 1번]

- **정할 것**: 담당·기한. **A-04·A-06 검증보다 반드시 선행** — 정기접수(반복 이동)가 즉시콜 필터에 섞이면 주간 패턴 규칙성이 인위적으로 강해져 A-04 계절성 검증이 "통과" 쪽으로 왜곡됨. A-06 첨두 대조(07·14시)도 같은 필터 의존
- **풀리는 것**: A-04·A-06 검증의 입력(즉시콜 필터) 확정
- **안 정하면**: A-04 검증을 돌려도 결과를 신뢰 못 함 — 재검증 비용 발생

### 3-4. ★ A-04 계절성 검증 착수 + 대표 주 선정 기준 고정 [관문 A 블로커 — 원 안건표에 없던 추가]

- **정할 것**: 담당·기한 + **대표 주 선정 기준을 검증 결과 확인 전에 고정**(사후 선택 차단 — ASSA 조치란 명시 사항)
- **풀리는 것**: 유일한 XX 등급 해소 경로 → 관문 A 통과 조건(XX 0건) → 6단계 실행 설계
- **안 정하면**: **관문 A 무기한 통과 불가** — 이 회의에서 가장 뒤가 긴 배정

### 3-5. A-07 차고지 44개 좌표·운영 상태 검증

- **정할 것**: 담당·기한 (3-3·3-4와 독립 — 병렬 가능)
- **풀리는 것**: baseline 상수(차고지 44개)의 신뢰도. D-03=(a) 전제 데이터
- **안 정하면**: baseline 자체가 미검증 상수 위에 놓임

### 3-6. 병합 파일럿

- **정할 것**: 담당·기한 (병렬 가능)
- **풀리는 것**: 픽업거리 실측 기준값 확보 + 파이프라인 검증
- **안 정하면**: 지표 정의표의 픽업거리 칸("병합 후 산출") 공란 지속
